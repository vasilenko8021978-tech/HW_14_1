# HW_14_1 — Категории и товары

Проект реализует базовую структуру интернет-магазина с поддержкой товаров и категорий.

## 📦 Описание

Реализованы два класса:
- `Product` — описывает отдельный товар (название, описание, цена, количество):
- Поддержка приватного атрибута цены (`__price`)
- Геттер и сеттер для цены с валидацией (цена > 0)
- Класс-метод `new_product()` для создания товара из словаря
- Автоматическое объединение дубликатов (по названию) с суммированием остатков и выбором максимальной цены
- `Category` — описывает категорию товаров и ведёт учёт:
- общего количества категорий,
- общего количества товаров во всех категориях.
Реализует:
- Приватный список товаров (`__products`)
- Метод `add_product()` для безопасного добавления товаров
- Геттер `@property products`, возвращающий строку в формате:  
    `Название, X руб. Остаток: Y шт.`  
- Атрибуты класса: `category_count`, `product_count` — автоматически обновляются при создании объектов

Классы поддерживают автоматическое обновление счётчиков при создании новых объектов.
