# HW_14_1 — Категории и товары

Проект реализует объектно-ориентированную модель интернет-магазина с поддержкой товаров, категорий, защиты данных и магических методов.

## 📦 Основные возможности

### Базовый класс `Product`
- Приватный атрибут цены (`__price`) с валидацией: цена не может быть ≤ 0
- Геттер `price` для безопасного чтения значения
- Класс-метод `new_product()` создаёт товар из словаря; при совпадении названия — объединяет остатки и выбирает максимальную цену
- Строковое представление:  
  `Название, X руб. Остаток: Y шт.`
- Поддержка сложения: `product1 + product2` → сумма `(цена × количество)`

### Классы-наследники
Реализованы два специализированных класса:

#### `Smartphone` (Смартфон)
Дополнительные атрибуты:
- `efficiency` — производительность (строка)
- `model` — модель устройства
- `memory` — объём встроенной памяти (ГБ)
- `color` — цвет

#### `LawnGrass` (Газонная трава)
Дополнительные атрибуты:
- `country` — страна-производитель
- `germination_period` — срок прорастания
- `color` — цвет

Оба класса наследуются от `Product` и полностью поддерживают его функциональность.

### Класс `Category`
- Приватный список товаров (`__products`)
- Метод `add_product()` принимает **только экземпляры `Product` или его наследников** (проверка через `isinstance`)
- Геттер `products` возвращает строку со всеми товарами (по одному на строку)
- Строковое представление:  
  `Название категории, количество продуктов: Z шт.`  
  (где `Z` — сумма `quantity` всех товаров в категории)
- Атрибуты класса:
  - `category_count` — общее число созданных категорий
  - `product_count` — общее число добавленных товаров

### Безопасность и ограничения
- **Сложение**: можно складывать только товары **одинакового типа** (например, `Smartphone + Smartphone`). Попытка сложить `Smartphone + LawnGrass` вызывает `TypeError`. Реализовано через `type(self) is type(other)`.
- **Добавление**: нельзя добавить в категорию объект, не являющийся `Product` или его наследником. Выбрасывается `TypeError`.

### Тестирование 
Проект покрыт автоматическими тестами с использованием pytest. Тесты проверяют:
- корректную инициализацию объектов Product и Category
- работу приватных атрибутов (__price, __products)
- валидацию цены через сеттер
- формат вывода геттера products
- автоматическое обновление счётчиков category_count и product_count
- логику new_product() (включая объединение дубликатов)
- строковые представления через __str__
- сложение товаров через __add__
- интеграционные сценарии, соответствующие логике заданий

### Дополнительно
- Реализован итератор `CategoryIterator` для перебора товаров в цикле `for`
